# AdGuardHome-Restore

Utilities for AdGuard Home backup, restore, and DNS monitoring.

## DNS monitor (Docker)

A headless monitor for multiple AdGuard Home DNS instances is available in
[`AdguardHome-Restore/`](AdguardHome-Restore/README.md). It checks configured DNS server
IPs and sends Telegram alerts on failure and recovery.

See the component README for setup, Docker Compose, and environment variables.
